createSolver(cfg, optopt) → {Object}

Description:

    每輪為一次w-trade-solve estimFinder(隨機方向與指標組成，於訓練期率定門檻與止盈止損)，達門檻之策略由estimKeys寫入策略庫(同tkid僅於更佳時覆寫) 預設engine為'fast'(加速評估核心，存檔前官方重跑)，'full'為全程官方runStrategy opt.workers為0時於本程序內循序執行(opt可含函數)，>0時以worker_threads平行執行(opt除事件欄位外不可含函數，改用closeOnly等旗標) 停止條件: maxStrategies(策略庫檔數達此即停)、maxRounds(總輪數)、maxTimeMs、shouldStop(status) => bool、或呼叫stop()；起跑前即成立者不起任何輪次(workers>0亦同，不起worker)；workers>0時各worker每輪結束皆等主程序放行才起下一輪，故停止條件成立時進行中之他worker至多再完成當輪(總輪數至多超出workers-1) 資源閘: opt.gate為async ({workerId,...status}) => {}，每輪起跑前(含workers>0各worker之第1輪)由主程序await之後才放行，可於其中量CPU/RAM，超限時延後resolve以節流；閘resolve後再查一次停止條件，成立即不放行(workers>0時所有worker，含仍在別的閘內等待者，皆收到stop並結束)；閘拋錯(含rejection)記入errors並觸發onError，照常放行；已要求停止後不再呼叫閘；stop()隨時生效(不等閘)，shouldStop、maxTimeMs、maxStrategies於輪次結束與每個閘resolve後判定，閘不resolve者不會被判定；停止後閘之promise不被取消(閘內宜自行檢查停止)

(async) parfor(fpWorker, jobs, optopt) → {Promise}

Description:

  • 輕量持久worker pool平行執行器，以原生worker_threads把CPU密集計算分散到多核心，免任何編譯步驟

    worker協定(worker entry檔須遵守):

    1. 經workerData收initData(一次)
    2. 收{ k, job } → 計算 → 回{ k, r }
    3. 單job失敗回{ k, err }(err為字串) → 不炸批，主程序印錯後續跑
    4. worker載入/init失敗 → 整批fail-fast拋錯
    5. worker不得自行退出；整批完成前之任何退出、建立失敗、結果反序列化失敗、job無法結構化複製、cb拋錯 → 皆整批fail-fast拋錯並terminate全部worker
    6. worker entry須綁parentPort.on('messageerror', (err) => { throw err })
Source:
  • util/parfor.mjs, line 33
Example

await parfor(new URL('./sweepSingle_worker.mjs', import.meta.url), jobs, { takeLimit: 4, initData: sc, cb: (r, k) => console.log(k, r) })
